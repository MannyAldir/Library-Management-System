# Library Management System
Manage library with object oriented programming. Allows library to add books, search by author and process books.

## Reason for upload
Practice object oriented programming principles. Implement a summer plan that is geared towards software development and artificial intelligence.

## Features
- Checkin/Checkout book
- Check book availability by title, author name and Isbn
- Search book by author name
- Add book to library system

## Setup
https://github.com/MannyAldir/Library-Management-System.git
cd Library-Management-System
uv sync
uv run main.py

## Tech Stack
- Python 3.12
- uv - dependency management
- ruff - linting and formatting
- mypy - strict static type checking
